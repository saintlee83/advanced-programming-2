# 서울 생활인구 분석기 (Hotplace Analyzer)

`고급프로그래밍2_오프닝.pdf` 의 **Project 1** — "두 개 파일을 입력받아 분석 1·2·3·4를
할 수 있는 프로그램을 UI로 만들어서 구현하기" — 를 PyQt5 애플리케이션으로 구현한 것이다.

데이터는 `Univ_Programming1/Lectures/midterm/data` 의 서울시 생활인구 자료를 그대로 쓴다.

* `LOCAL_PEOPLE_DONG_201912.csv` — 2019년 12월, 행정동 424곳 × 31일 × 24시간 (315,456행 / 171MB)
* `dong_code.csv` — 행정동 코드표 (시도 / 시군구 / 행정동명)

---

## 실행

```bash
uv sync                              # PyQt5 · matplotlib 설치
uv run studies/study1/app.py         # GUI 실행
```

데이터 폴더는 자동으로 찾는다. 다른 곳에 있다면 화면에서 폴더 아이콘으로 고르거나,
`HOTPLACE_DATA_DIR` 환경변수 또는 명령줄 인자로 지정한다.

```bash
uv run studies/study1/app.py --population /경로/LOCAL_PEOPLE_DONG_201912.csv \
                             --codes      /경로/dong_code.csv
```

GUI 없이 결과만 확인하려면:

```bash
uv run studies/study1/app.py --check                 # 상위 지역 + 분석 1~5 점검
uv run studies/study1/app.py --check 압구정동 --out ./out   # 그래프를 PNG로 저장
```

```
왼쪽 패널            01 데이터 연결: 생활인구 CSV + 행정동 코드 CSV, 로딩 진행률
                     02 지역 탐색: 지역 A / B, 행정동 검색, 생활인구 TOP 20
오른쪽 대시보드      선택 지역 · 분석 기간
                     지역 A / B 각각 동일한 핵심 지표 4개를 나란히 표시
                     분석 탭 5개: 모든 항목에서 두 지역 함께 분석
                     공통 축 확대·이동·초기화 · 두 지역 이미지/CSV 내보내기

상태 표시줄          데이터 로딩, 검색, 저장 결과 안내
```

밝은 배경과 카드 중심의 레이아웃으로 입력 영역과 분석 결과를 구분했다.
처음에는 시스템 테마를 따르며, 상단 버튼으로 밝은/어두운 모드를 전환할 수 있다.
최소 창 크기는 1080 × 740이며 높이가 부족하면 각 패널을 스크롤할 수 있다.
차트는 읽을 수 있는 높이를 유지해 작은 창에서도 잘리지 않는다.
파일 경로 전체는 입력 칸에 마우스를 올려 확인할 수 있다.
기존 최대·최소 시간대, 주야 격차, 성비 등의 수치는 **상세 통계** 창에서 확인·복사할 수 있다.

### 두 지역 비교

데이터를 불러온 뒤 왼쪽에서 지역 A와 B를 선택한다. 두 지역은 동일한 크기의 카드와
그래프로 표시되며, **모든 분석 탭과 요약 통계에서 같은 항목을 나란히 비교**할 수 있다.

* 시간대별·평일/주말·성별 분석은 두 그래프의 인구 축을 0부터 동일한 최댓값까지 맞춘다.
* 연령별 피라미드는 두 지역 모두 동일한 좌우 대칭 인구 축을 사용한다.
* 확대·이동 시 두 그래프의 축이 함께 바뀐다. ‘추이 겹쳐보기’에서는 한 그래프에 두 지역을 표시한다.
* 어느 지역을 바꾸든 현재 분석 탭을 유지한다. **지역 A ↔ B 서로 바꾸기**로 좌우를 바꿀 수 있다.
* 검색과 생활인구 TOP 20은 **검색 · 순위 선택 대상**에서 A 또는 B를 선택해 적용한다.
* 같은 지역을 양쪽에 선택해도 두 결과를 동일하게 표시하며, 상단에 같은 지역임을 안내한다.
* CSV에는 A와 B의 값이 모두 포함되고 각 열에 지역명과 분석 항목이 표시된다.

### 강의자료 `Hotplace` 클래스와의 차이

강의자료의 클래스 설계(속성 `name` / `code`, 메서드 `analysis1~4`, `graph_plot`)는 그대로 두되
**계산과 그리기를 분리**했다. `analysisN()` 은 `plt.show()` 를 직접 부르지 않고
`LineSeries` (제목 · 계열 이름 · 24개 값) 를 돌려주고, 그리는 일은 `plotting.py` 가 맡는다.

* `plt.show()` 는 별도 창을 띄워 Qt 이벤트 루프와 충돌한다 → 그래프를 창 안에 넣으려면 분리가 필요
* 분석 결과를 GUI 없이 검증하거나 CSV로 내보낼 수 있다

GUI는 `PairedAnalysis`로 두 지역의 동일한 분석 결과를 묶어 표시하고 내보낸다.
기존 `Hotplace.analysis1~5`의 계산 방식과 명령줄 `--check`는 유지한다.

### 설계 메모

**원본을 통째로 들고 있지 않는다.** 171MB CSV를 `list()` 로 올리면 메모리 수 GB에
분석할 때마다 31만 행을 다시 훑어야 한다. 읽으면서 행정동별 24시간 누적치로 줄여 담으므로
(424개 동 × 24시간), 파일을 한 번만 훑고 이후 분석은 즉시 끝난다.

**한 번 집계한 결과는 캐시한다.** 첫 로딩 약 4초, 두 번째부터는 `.cache/` 에서 즉시.
원본 파일의 크기·수정시각이 바뀌면 캐시는 자동으로 무효가 된다.

**로딩은 별도 스레드에서.** `QThread` 로 돌려 로딩 중에도 화면이 멈추지 않고 진행률이 보인다.

**행정동명 중복 처리.** '신사동'은 강남구와 관악구 두 곳에 있다. 강의자료의 `dong_search()` 는
먼저 찾은 하나만 돌려주지만, 이 앱은 콤보를 `자치구 + 행정동` 으로 두고
검색 결과가 여럿이면 선택 창을 띄운다.

**그래프 색과 테마.** 화면과 차트가 `theme.py`의 공통 팔레트를 사용한다.
계열 색은 파랑 → 주황 고정 순서이며, 두 번째 계열은 점선으로도 구분한다.
범례와 정점 직접 라벨을 함께 두고, 단일 계열에는 옅은 면적 채움을 사용한다.
모드 전환 시 차트 배경, 축, 라벨과 도구모음 아이콘도 함께 갱신된다.

| | 배경 | 계열 1 | 계열 2 |
|---|---|---|---|
| 밝은 테마 | `#ffffff` | `#2a78d6` | `#eb6834` |
| 어두운 테마 | `#182231` | `#68aaff` | `#ff9b67` |

## 검증

두 지역 비교의 회귀 검증은 실제 CSV 없이 합성 데이터로 실행할 수 있다.
지역을 교환했을 때의 대칭성, 모든 탭의 양쪽 CSV 열, 동일한 축과 그래프 크기,
A/B 검색과 동일 지역 선택을 확인한다.

```bash
uv run python -m unittest discover -s studies/study1/tests -v
```

`--check` 로 분석 1~5가 모두 도는지 확인할 수 있다.
집계 값은 강의자료 방식(31만 행을 직접 순회)으로 다시 계산한 결과와 **오차 0** 으로 일치한다.

예시 (강남구 역삼1동, 2019년 12월):

```
· 일평균 생활인구        112,399 명
· 최대 혼잡 시간대  14시  (162,430 명)
· 최소 시간대        4시  ( 67,902 명)
· 주야 격차         주간 150,478 / 야간  70,034  (배율 2.15)
· 평일·주말         평일 123,126 / 주말  86,180  (주말비 0.70)
· 성비              남 51.3% / 여 48.7%
· 추정 상권 성격    평일 오피스형 (업무 밀집)
```

'추정 상권 성격'은 주말비·주야 배율·정점 시간대를 조합한 **규칙 기반 참고값**이며
통계적 분류가 아니다 (`Hotplace._character`).
