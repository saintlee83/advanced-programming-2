# Hello Kitty SVG

- Source page: https://svgcrown.com/download.php?category=hello-kitty&id=3
- Download: https://svgcrown.com/file/hello-kitty/3.zip (`3.svg`)
- Retrieved: 2026-09-16
- Character: Hello Kitty, Sanrio.

`hello-kitty.svg` keeps all 12 drawing paths from the downloaded SVG. Only unused
Adobe editor metadata / invalid editor namespace declarations were removed, the
viewBox was fitted to the drawing with padding, and fills were matched to the
user-selected [Loading.io Hello Kitty palette](https://loading.io/color/feature/HelloKitty/).
The face proportions and path coordinates are unchanged.

The source offers the file as a free SVG download. No separate license was
included in the ZIP; this attribution does not grant rights to Sanrio's character.

Palette: red `#F90013`, yellow `#FFE700`, white `#FFFFFF`, blue `#0054AE`,
brown `#251815`. The app bundles the SVG locally and loads it without network access.
