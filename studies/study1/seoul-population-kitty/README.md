# 서울 생활인구 비교 · Kitty

PyQt5 / Qt 5.15 기반의 서울 생활인구 분석 앱이다.
원본 `../seoul-population/`의 분석 모델과 UI 스타일에 헬로키티 색상을 적용한다.
사용 흐름은 **데이터 불러오기 → 차트 보기** 두 단계이며, 차트 화면은 왼쪽 지역 선택·지표, 오른쪽 비교 차트로 구성한다.
키티 SVG는 앱 제목 옆과 첫 화면, 창 아이콘에 사용한다.

## 화면 구성

| 요소 | 원본 | 이 버전 |
|---|---|---|
| 메뉴 | 왼쪽 세로 메뉴, 4개 화면 | 없음. 데이터 불러오기 → 차트 보기 |
| 지역 선택·지표 | 화면 위 가로 배치 | 왼쪽 세로 패널 |
| 차트 선택 | 두 줄 탭 | 분석 분류·차트 선택기 |
| A/B 비교 차트 | 좌우 배치 | 위아래 배치, 공통 축 유지 |
| 비교 리포트 | 세 열 표 | 없음(`--check`가 텍스트로 출력) |
| 지역 찾기 | 상단 검색 바 | 없음 |
| 파일 입력 | ‘데이터’ 화면의 경로 입력란 | 버튼 → 파일 선택 창에서 두 CSV를 함께 선택 |
| 히트맵 2종 | 선택 가능 | 선택 목록에서 비활성화 |

11가지 차트(히트맵 2종은 비활성화, 서울 속 위치는 삭제), 데이터 검증, PNG·CSV 내보내기를 지원한다.

## 실행

이 폴더(`studies/study1/seoul-population-kitty/`)에서 실행한다.
의존성(PyQt5, PyQt-Fluent-Widgets, matplotlib)은 이 폴더의 `pyproject.toml`로 관리하며, `uv sync`가 이 폴더에 `.venv`를 만든다.
원본 앱이 쓰는 저장소 루트 환경(PySide6)과는 분리되어 있다. PySide6용과 PyQt5용 Fluent Widgets가
같은 패키지 이름(`qfluentwidgets`)으로 설치되어 한 환경에 함께 둘 수 없기 때문이다.

```bash
cd studies/study1/seoul-population-kitty
uv sync
uv run app.py
```

저장소 루트에서는 `uv run --project studies/study1/seoul-population-kitty studies/study1/seoul-population-kitty/app.py`로 실행한다.

**데이터 불러오기** 버튼을 누르면 파일 선택 창이 열린다. 다음 두 CSV를 함께 선택한다(⌘ 또는 Ctrl 키를 누른 채 클릭).
파일 선택 창은 다른 창에 가려지지 않도록 ‘항상 맨 앞’으로 뜬다(Qt 파일 창 + `WindowStaysOnTopHint`).
하나만 고르면 나머지 파일을 이어서 묻는다. 어느 쪽이 생활인구 파일인지는 첫 줄의 열 개수(32열 이상)로 가리므로 고르는 순서와 파일 이름은 상관없다.

- `LOCAL_PEOPLE_DONG_YYYYMM.csv`: 기준일, 시간대, 행정동 코드, 총생활인구, 남녀 각 14개 연령대
- `dong_code.csv`: 기존 강의자료의 한글/영문 2줄 헤더 및 행정동 코드표

파일 선택 창은 기본 데이터 폴더에서 열린다. `HOTPLACE_DATA_DIR`, 저장소 루트의 `data/`, 형제 저장소
`Univ_Programming1/Lectures/midterm/data/` 순으로 찾는다. `--check`도 같은 폴더를 쓴다.
저장소 루트 후보는 `pyproject.toml`이 있는 상위 폴더들이며, 가까운 폴더부터 차례로 확인한다.
`--population`과 `--codes`를 모두 주면 창이 열리자마자 그 파일을 불러온다.

```bash
uv run app.py --population /path/LOCAL_PEOPLE_DONG_201912.csv --codes /path/dong_code.csv
uv run app.py --check 역삼1동
uv run app.py --check 역삼1동 --out /tmp/hotplace-charts
```

`--check`는 창을 열지 않고 분석 1~13, 관측 품질, 비교 리포트를 출력한다.
`--out`을 함께 지정하면 13개 PNG를 저장한다. 지역을 생략하면 상위 지역을 선택한다.
데이터에 지역이 하나뿐이어도 동작한다.

### macOS 앱 빌드

Apple Silicon Mac에서 이 폴더 기준:

```bash
uv run --with 'pyinstaller>=6.16,<7' pyinstaller --noconfirm Hotplace.spec
open dist/HotplaceKitty.app
```

`HotplaceKitty.app`(Finder·Dock 표시 이름은 ‘서울 생활인구 비교 · Kitty’)에는 Python·PyQt5·차트 리소스와 키티 SVG가 포함된다. CSV 데이터는 별도로 연결한다.
앱 번들의 집계 캐시는 `~/Library/Caches/Hotplace/`에 저장한다.
빌드 산출물 `build/`, `dist/`는 Git에서 제외한다.

### Windows 앱 빌드

PyInstaller는 실행한 운영체제용으로만 빌드하므로 Mac에서는 `.exe`를 만들 수 없다. 두 가지 방법이 있다.

- **GitHub Actions**: 저장소의 Actions → *Windows build* → *Run workflow* (또는 `gh workflow run windows-build.yml`). 끝나면 실행 페이지의 Artifacts에서 `HotplaceKitty-windows-x64`를 내려받는다.
- **Windows PC에서 직접**: 이 폴더에서 위와 같은 `uv run … pyinstaller --noconfirm Hotplace.spec`을 실행하면 `dist\HotplaceKitty\HotplaceKitty.exe`가 만들어진다.

`HotplaceKitty.exe`는 같은 폴더의 `_internal\`과 함께 있어야 실행된다. 서명하지 않은 실행 파일이라 처음 실행할 때 SmartScreen 경고가 뜨면 ‘추가 정보 → 실행’을 누른다. 집계 캐시는 `_internal\.cache\`에 저장한다.
Windows용 `PyQt5-Qt5` 휠은 5.15.2가 마지막이라 `pyproject.toml`에서 Windows만 그 버전으로 고정한다.

## 사용 가능한 화면

| 화면 | 기능 |
|---|---|
| 데이터 불러오기 | 파일 두 개 선택, 백그라운드 로딩·진행률 |
| 차트 보기 | 지역 A/B 선택, 네 가지 지표 비교표, 3개 묶음 11개 차트, PNG·CSV 저장, 상권 유형(추정), 다른 데이터 불러오기 |

불러오기가 끝나면 차트 화면으로 바로 넘어간다. 상단 메뉴와 ‘데이터’·‘지역 찾기’·‘비교 리포트’ 화면은 없다(원본에는 있다).
관측 완전성·중복 행 수는 `--check`로 확인한다.

### 디자인

- 글꼴, 버튼, 얇은 테두리, 모서리는 원본 스타일을 사용한다.
- 색상은 [Loading.io Hello Kitty 팔레트](https://loading.io/color/feature/HelloKitty/)의
  빨강 `#F90013`, 노랑 `#FFE700`, 흰색 `#FFFFFF`, 파랑 `#0054AE`, 갈색 `#251815`를 기준으로 한다.
  배경과 경계에는 옅은 변형을 사용한다.
- 시스템 설정과 무관하게 밝은 테마로 고정하며, 테마 전환 버튼은 표시하지 않는다.
- 지역 A는 빨강, 지역 B는 파랑이다. A/B 문자도 함께 표시한다.
- 한 지역 안의 두 계열은 선 모양과 명도로 구분한다. 히트맵은 파랑 단색 계열을 쓴다.
- 키티 얼굴은 [SVG Crown의 SVG](https://svgcrown.com/download.php?category=hello-kitty&id=3)를
  원래 비율로 표시한다. 출처와 파일은 `hotplace/assets/`에 포함한다.
- 카드 배치를 유지하며, 장식 배경이나 별도 브랜드 슬로건은 사용하지 않는다.

### 화면 전환

- 두 화면과 차트는 애니메이션 없이 즉시 바뀐다(기본 `QStackedWidget`).
- Fluent 위젯에 들어 있는 움직임도 같은 모양을 유지한 채 끈다: 휠 스크롤, 진행 막대, 콤보 목록 펼침, 완료 알림의 미끄러짐·페이드.
- 최소 창 크기 1080 × 740. 내용은 세로로 스크롤되며 차트 높이를 유지한다.
- 지역과 차트 선택은 화면을 이동해도 유지된다. 동일 지역 A/B 선택도 지원한다(같다는 안내를 표시).

### 차트 묶음

‘분석 분류’에서 묶음을 고르면 ‘차트’에서 그 묶음의 차트를 선택할 수 있다.
묶음을 오가도 묶음마다 마지막으로 본 차트를 기억한다.

| 묶음 | 차트 |
|---|---|
| 하루 흐름 | 시간대 · 평일·주말 · 겹쳐 보기 · 시간대별 차이 · 흐름 비교 |
| 요일·날짜 | 요일별 · 일별 추이 |
| 성별·연령 | 성별 · 남녀 비율 · 연령 · 연령 비중 |

히트맵 두 개(요일×시간, 연령×시간)는 `hotplace/ui.py`의 `DISABLED_CHARTS = frozenset({6, 12})`로 목록에서 뺐다.
계산·그리기 코드는 남아 있어 집합에서 번호를 지우면 다시 나타난다. 다른 차트도 같은 방법으로 뺄 수 있다(번호 = `analysis` 번호 − 1).

### 비교와 내보내기

지역별로 위아래에 그리는 차트(시간대·평일/주말·성별·일별·요일별·남녀 비율)는 두 지역의 축 범위를 맞춘다.
피라미드는 같은 좌우 대칭 축을 사용한다.
마우스를 올리면 두 지역의 값을 읽어 주는 기능(마우스 판독)은 구현되어 있지만 이 버전에서는 꺼 두었다.
`hotplace/plotting.py`의 `HOVER_ENABLED`를 `True`로 바꾸면 다시 동작한다. 이 기능은 matplotlib 기본 기능이 아니라 직접 만든 것이다.
확대·이동은 두 차트에 함께 적용된다.

CSV는 UTF-8 BOM으로 저장하며 양쪽 지역명과 계열을 포함한다.
관측이 없거나 계산할 수 없는 값은 빈 셀로 내보낸다.

## 14가지 분석

계산 메서드는 14개 모두 있다. 히트맵인 `analysis7`·`analysis13`은 GUI 차트 목록에서 비활성화했고 `--check`에서만 실행된다. `analysis14`는 이 앱 어디에서도 부르지 않는다.

| 메서드 | 내용 | 계산 기준 |
|---|---|---|
| `analysis1` | 시간대별 생활인구 | 시간대별 누적 ÷ 해당 시간의 실제 관측 일수 |
| `analysis2` | 평일 / 주말 | 월~금 / 토~일의 시간대별 관측 평균 |
| `analysis3` | 남자 / 여자 | 성별 14개 연령대 합의 시간대별 관측 평균 |
| `analysis4(other)` | 두 지역 추이 | 두 지역의 시간대 평균을 한 차트에 표시 |
| `analysis5` | 연령 피라미드 | 각 성별·연령대 누적 ÷ 실제 관측 수 |
| `analysis6` | 일별 추세 | 24시간이 모두 있는 날의 평균 및 연속 7일 이동평균 |
| `analysis7` | 요일 × 시간 히트맵 | 월~일 각각의 시간대별 관측 평균 |
| `analysis8(other)` | 정규화 패턴 | 각 지역 시간대 평균을 100으로 환산 |
| `analysis9(other)` | 시간대별 차이 | 시간대마다 A 평균 − B 평균. 0선 위는 A, 아래는 B가 많다 |
| `analysis10` | 요일별 평균 | `analysis7`의 요일 행마다 관측된 시간대 평균의 평균 |
| `analysis11` | 시간대별 남녀 비율 | 여성 = 여자 14개 연령대 합 ÷ 남녀 28개 합 × 100, 남성 = 100 − 여성. 점선은 50% |
| `analysis12(other)` | 연령 비중 비교 | 지역마다 연령대(남녀 합) ÷ 전체 × 100을 두 점으로 비교 |
| `analysis13` | 시간대별 연령 구성 | 시간마다 그 시간의 연령 집계 합을 100으로 본 연령대 비중. 관측 없는 시간은 빈 칸 |
| `analysis14(other, codebook)` | 서울 속 위치 | 코드표와 매칭된 모든 행정동의 낮 ÷ 밤, 주말 ÷ 평일 배율. **이 앱에서는 쓰지 않는다**(화면·그리기 코드·`--check`에서 삭제, 메서드만 원본과 같게 남음) |

원래의 완전한 데이터셋에서는 분석 1~5의 계산 값이 유지된다.
관측이 빠진 데이터에서는 실제 관측 횟수를 분모로 사용한다.
전체 누락 시간대·없는 평일/주말 그룹은 0으로 채우지 않는다.
날짜 사이의 빈 날도 일별 차트에 남겨 두며, 부분 일자는 일별 평균에서 제외한다.
이동평균은 연속한 7일이 모두 완전할 때만 산출한다.

> 생활인구는 특정 시간에 해당 지역에 존재하는 인구 추정치다.
> 화면의 ‘일평균’은 시간대 평균이며, 하루 고유 방문자 수나 유입량이 아니다.
> 공휴일은 별도 보정하지 않는다. 평일에 있는 공휴일은 평일 그룹에 들어간다.

## 비교 리포트 계산

`hotplace/analytics.py`는 GUI와 독립적으로 결과를 계산한다. 이 버전의 GUI에는 리포트 화면이 없고, `uv run app.py --check`가 텍스트 리포트를 출력한다.

- **붐비는 3시간:** 자정을 넘는 구간을 포함해 연속 3시간 평균이 가장 높은 구간.
- **시간대별 변동:** 관측된 시간대 평균의 모집단 표준편차 ÷ 평균 × 100. 가장 적은/많은 시간도 함께 표시한다.
- **20~39세 비중:** 성별·연령 집계 합계 중 20~39세 비중. 65세 이상 비중을 함께 표시한다.
- **관측 완전성:** 최초~최종 날짜 × 24시간 대비 실제 관측 비중. 통계적 신뢰도 점수가 아니다.
- **평소와 다른 날:** 평일/주말을 분리하고 각 그룹에 완전한 일자가 7일 이상일 때 중앙값·MAD로 계산한다.
  `수정 z = 0.67448975 × (일평균 − 그룹 중앙값) / MAD`, `|z| > 3.5`인 날을 표시한다.
  MAD가 0이거나 표본이 부족한 그룹은 판단을 보류한다. 표시된 일자가 오류나 특정 사건을 뜻하지는 않는다.
- **서울 내 순위:** 코드표와 매칭된 지역의 일평균 생활인구를 내림차순으로 정렬한다.
- **하루 흐름 유사도:** 두 지역에 공통 관측이 있는 시간대의 Pearson 상관계수.
  공통 시간대가 3개 미만이거나 한쪽 패턴이 일정하면 산출하지 않는다.
  0.9 이상 ‘매우 비슷함’, 0.7 이상 ‘비슷함’, 0.4 이상 ‘조금 비슷함’, 그 밖은 ‘다름’으로 함께 표시한다.
- **차이가 가장 큰 시간:** 공통 시간대에서 `|A − B|`가 가장 큰 시간과 어느 쪽이 얼마나 많은지.

‘상권 유형(추정)’은 주말/평일 배율·낮/밤 배율·가장 붐비는 시간으로 나눈 규칙 기반 참고값이다
(주말 상권형, 업무지구형, 주거지형, 혼합형).
표본이나 분모가 없으면 판단을 보류한다. 매출, 면적, 이동 경로, 예측 모델을 사용한 분류는 아니다.

## 데이터 처리

CSV를 한 번 읽으면서 행정동별 시간·성별·연령 합계와 날짜별 시간 관측을 보관한다.
원본 전체 행을 메모리에 올리지 않는다.

- 날짜·시간 범위, 숫자, 음수, NaN/무한대, 부족한 열을 검사한다. 잘못된 행은 행 번호를 포함한 오류로 알린다.
- 같은 `(행정동, 날짜, 시간)`은 첫 번째 행을 사용하고 이후 중복 행을 집계에서 제외한다.
- 코드표와 일치하는 지역이 하나도 없으면 연결 실패로 처리한다.
- 완전성의 지역 범위는 인구 파일에서 발견된 지역이다. 통째로 누락된 지역은 이 비율로 탐지하지 못한다.
- 이 폴더의 `.cache/`에 버전 4 집계를 저장한다. 파일 경로·크기·나노초 수정시각이 달라지면 다시 읽는다.
- 로딩은 `QThread`에서 실행하며, 종료 요청 시 중단 신호를 확인한 뒤 스레드를 정리한다.
- 재로딩이 실패해도 기존 분석 데이터는 유지한다.
