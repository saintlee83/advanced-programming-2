# 서울 생활인구 비교

강의 Project 1의 `Hotplace.analysis1~4`와 기존 연령 분석을 유지하고,
**PySide6 / Qt 6** 기반으로 확장한 데스크톱 분석 앱이다.
PySide6-Fluent-Widgets와 matplotlib를 사용하며 웹 서버는 필요하지 않다.

## 실행

이 폴더(`studies/study1/seoul-population/`)에서 실행한다.
의존성은 저장소 루트의 `pyproject.toml`로 관리하며, `uv`가 위쪽 폴더에서 자동으로 찾는다.

```bash
cd studies/study1/seoul-population
uv sync
uv run app.py
```

저장소 루트에서는 `uv run studies/study1/seoul-population/app.py`로 실행한다.

‘데이터’ 화면에서 다음 두 CSV를 지정한다.

- `LOCAL_PEOPLE_DONG_YYYYMM.csv`: 기준일, 시간대, 행정동 코드, 총생활인구, 남녀 각 14개 연령대
- `dong_code.csv`: 기존 강의자료의 한글/영문 2줄 헤더 및 행정동 코드표

`HOTPLACE_DATA_DIR`, 저장소 루트의 `data/`, 형제 저장소
`Univ_Programming1/Lectures/midterm/data/` 순으로 기본 경로를 찾는다.
저장소 루트는 `pyproject.toml`이 있는 가장 가까운 상위 폴더다.
명령줄 경로는 GUI의 파일 입력란에도 반영된다.

```bash
uv run app.py --population /path/LOCAL_PEOPLE_DONG_201912.csv --codes /path/dong_code.csv
uv run app.py --check 역삼1동
uv run app.py --check 역삼1동 --out /tmp/hotplace-charts
```

`--check`는 창을 열지 않고 14가지 분석, 관측 품질, 비교 리포트를 출력한다.
`--out`을 함께 지정하면 14개 PNG를 저장한다. 지역을 생략하면 상위 지역을 선택한다.
데이터에 지역이 하나뿐이어도 동작한다.

### macOS 앱 빌드

Apple Silicon Mac에서 이 폴더 기준:

```bash
uv run --with 'pyinstaller>=6.16,<7' pyinstaller --noconfirm Hotplace.spec
open dist/Hotplace.app
```

`Hotplace.app`(Finder·Dock 표시 이름은 ‘서울 생활인구 비교’)에는 Python·PySide6·차트 리소스가 포함된다. CSV 데이터는 별도로 연결한다.
앱 번들의 집계 캐시는 `~/Library/Caches/Hotplace/`에 저장한다.
빌드 산출물 `build/`, `dist/`는 Git에서 제외한다.

## 네 개의 화면

| 화면 | 기능 |
|---|---|
| 지역 비교 | 지역 A/B 선택·교환, 네 가지 비교 지표, 4개 묶음 14개 차트, PNG·CSV 저장, 상권 유형(추정) |
| 비교 리포트 | 하루 흐름 유사도·차이가 가장 큰 시간·일평균 차이, 항목별 A/B 비교표, 관련 차트로 이동, 텍스트 리포트 저장 |
| 지역 찾기 | 행정동·자치구·코드 검색, 같은 이름 중 고르기, 4개 기준으로 상위 20곳 정렬, A 또는 B에 넣기 |
| 데이터 | 파일 지정, 백그라운드 로딩·진행률, 행정동 수·기간·관측 완전성·중복 행 표시 |

첫 화면의 **데이터 불러오기**는 경로가 이미 채워져 있으면 바로 로딩을 시작하고, 아니면 ‘데이터’ 화면으로 이동한다.

### 디자인

- 화면 크롬(배경, 버튼, 선택 표시)은 무채색으로 두고 색은 데이터에만 쓴다. 지역 A는 파랑, 지역 B는 주황이다.
  두 색은 색각 이상 시뮬레이션에서도 구분되는지 검증했다.
- 한 지역 차트 안의 두 계열(평일/주말, 남자/여자)은 그 지역 색을 유지하고 선 모양(실선/점선)이나 명도로 구분한다.
  다른 지역의 색을 빌려 쓰지 않는다. 요일×시간 히트맵은 A/B와 겹치지 않는 보라 단색 계열을 쓴다.
- 페이지 제목과 설명은 상단 바에 한 번만 표시한다. 계산 기준 같은 주석은 한 곳에만 둔다.
- 밝은/어두운 테마를 지원한다. 어두운 테마는 같은 색상을 어두운 배경에 맞춰 조정한 값이다.

### 모션

- 페이지와 차트 전환에 220~240ms 페이드·슬라이드와 cubic easing 적용.
- 빠르게 여러 탭을 눌러도 현재 선택 상태는 즉시 반영된다. 창 크기와 테마를 바꾸면 진행 중인 전환을 정리한다.
- 왼쪽 아래 **애니메이션 끄기**로 전환 효과를 끌 수 있다. 실행 전 `HOTPLACE_REDUCED_MOTION=1`로도 설정한다.
- 최소 창 크기 1080 × 740. 내용은 세로로 스크롤되며 차트 높이를 유지한다.
- 지역과 차트 탭은 화면을 이동해도 유지된다. 동일 지역 A/B 선택도 지원한다(같다는 안내를 표시).

### 차트 묶음

차트가 많아 탭을 두 줄로 나눈다. 위 줄에서 묶음을 고르면 아래 줄에 그 묶음의 차트가 나온다.
묶음을 오가도 묶음마다 마지막으로 본 차트를 기억한다.

| 묶음 | 차트 |
|---|---|
| 하루 흐름 | 시간대 · 평일·주말 · 겹쳐 보기 · 시간대별 차이 · 흐름 비교 |
| 요일·날짜 | 요일별 · 요일×시간 · 일별 추이 |
| 성별·연령 | 성별 · 여성 비율 · 연령 · 연령 비중 · 연령×시간 |
| 서울 전체 | 서울 속 위치 |

### 비교와 내보내기

지역별로 나란히 그리는 차트(시간대·평일/주말·성별·일별·요일별·여성 비율)는 두 지역의 축 범위를 맞춘다.
피라미드는 같은 좌우 대칭 축, 두 히트맵은 같은 색상 범위를 사용한다.
선·막대 차트에서 마우스를 움직이면 같은 시간·날짜·요일의 실제 값을 표시한다.
히트맵은 칸, 연령 비중은 연령대 줄, 서울 속 위치는 가장 가까운 점의 값을 표시한다.
확대·이동도 연결되며, PNG 저장 시 마우스 가이드는 제외한다.

CSV는 UTF-8 BOM으로 저장하며 양쪽 지역명과 계열을 포함한다.
관측이 없거나 계산할 수 없는 값은 빈 셀로 내보낸다.
히트맵 CSV는 요일 7행(또는 연령대 14행)과 A/B 각각의 24시간 열로 구성한다.
서울 속 위치 CSV는 모든 행정동의 두 배율과 비교 지역 표시(A/B)를 담는다.
비교 리포트의 텍스트 파일에는 기간, 지역, 비교 수치, 항목별 A/B 값과 각 항목의 계산 기준이 들어간다.

## 14가지 분석

| 메서드 | 내용 | 계산 기준 |
|---|---|---|
| `analysis1` | 시간대별 생활인구 | 시간대별 누적 ÷ 해당 시간의 실제 관측 일수 |
| `analysis2` | 평일 / 주말 | 월~금 / 토~일의 시간대별 관측 평균 |
| `analysis3` | 남자 / 여자 | 성별 14개 연령대 합의 시간대별 관측 평균 |
| `analysis4(other)` | 두 지역 추이 | 두 지역의 시간대 평균을 한 차트에 표시 |
| `analysis5` | 연령 피라미드 | 각 성별·연령대 누적 ÷ 실제 관측 수 |
| `analysis6` | 일별 추세 | 24시간이 모두 있는 날의 평균 및 연속 7일 이동평균 |
| `analysis7` | 요일 × 시간 히트맵 | 월~일 각각의 시간대별 관측 평균 |
| `analysis8(other)` | 정규화 패턴 | 각 지역 시간대 평균을 100으로 환산 |
| `analysis9(other)` | 시간대별 차이 | 시간대마다 A 평균 − B 평균. 0선 위는 A, 아래는 B가 많다 |
| `analysis10` | 요일별 평균 | `analysis7`의 요일 행마다 관측된 시간대 평균의 평균 |
| `analysis11` | 시간대별 여성 비율 | 여자 14개 연령대 합 ÷ 남녀 28개 합 × 100. 점선은 50% |
| `analysis12(other)` | 연령 비중 비교 | 지역마다 연령대(남녀 합) ÷ 전체 × 100을 두 점으로 비교 |
| `analysis13` | 시간대별 연령 구성 | 시간마다 그 시간의 연령 집계 합을 100으로 본 연령대 비중. 관측 없는 시간은 빈 칸 |
| `analysis14(other, codebook)` | 서울 속 위치 | 코드표와 매칭된 모든 행정동의 낮 ÷ 밤(로그 눈금), 주말 ÷ 평일 배율. 상권 유형 기준선을 함께 표시 |

원래의 완전한 데이터셋에서는 분석 1~5의 계산 값이 유지된다.
관측이 빠진 데이터에서는 실제 관측 횟수를 분모로 사용한다.
전체 누락 시간대·없는 평일/주말 그룹은 0으로 채우지 않는다.
날짜 사이의 빈 날도 일별 차트에 남겨 두며, 부분 일자는 일별 평균에서 제외한다.
이동평균은 연속한 7일이 모두 완전할 때만 산출한다.

> 생활인구는 특정 시간에 해당 지역에 존재하는 인구 추정치다.
> 화면의 ‘일평균’은 시간대 평균이며, 하루 고유 방문자 수나 유입량이 아니다.
> 공휴일은 별도 보정하지 않는다. 평일에 있는 공휴일은 평일 그룹에 들어간다.

## 비교 리포트 계산

`hotplace/analytics.py`는 GUI와 독립적으로 결과를 계산한다. 화면의 비교표와 텍스트 리포트가 같은 항목(`ROWS`)을 쓴다.

- **붐비는 3시간:** 자정을 넘는 구간을 포함해 연속 3시간 평균이 가장 높은 구간.
- **시간대별 변동:** 관측된 시간대 평균의 모집단 표준편차 ÷ 평균 × 100. 가장 적은/많은 시간도 함께 표시한다.
- **20~39세 비중:** 성별·연령 집계 합계 중 20~39세 비중. 65세 이상 비중을 함께 표시한다.
- **관측 완전성:** 최초~최종 날짜 × 24시간 대비 실제 관측 비중. 통계적 신뢰도 점수가 아니다.
- **평소와 다른 날:** 평일/주말을 분리하고 각 그룹에 완전한 일자가 7일 이상일 때 중앙값·MAD로 계산한다.
  `수정 z = 0.67448975 × (일평균 − 그룹 중앙값) / MAD`, `|z| > 3.5`인 날을 표시한다.
  MAD가 0이거나 표본이 부족한 그룹은 판단을 보류한다. 표시된 일자가 오류나 특정 사건을 뜻하지는 않는다.
- **서울 내 순위:** 코드표와 매칭된 지역의 일평균 생활인구를 내림차순으로 정렬한다.
- **하루 흐름 유사도:** 두 지역에 공통 관측이 있는 시간대의 Pearson 상관계수.
  공통 시간대가 3개 미만이거나 한쪽 패턴이 일정하면 산출하지 않는다.
  0.9 이상 ‘매우 비슷함’, 0.7 이상 ‘비슷함’, 0.4 이상 ‘조금 비슷함’, 그 밖은 ‘다름’으로 함께 표시한다.
- **차이가 가장 큰 시간:** 공통 시간대에서 `|A − B|`가 가장 큰 시간과 어느 쪽이 얼마나 많은지.

‘상권 유형(추정)’은 주말/평일 배율·낮/밤 배율·가장 붐비는 시간으로 나눈 규칙 기반 참고값이다
(주말 상권형, 업무지구형, 주거지형, 혼합형).
표본이나 분모가 없으면 판단을 보류한다. 매출, 면적, 이동 경로, 예측 모델을 사용한 분류는 아니다.

## 데이터 처리

CSV를 한 번 읽으면서 행정동별 시간·성별·연령 합계와 날짜별 시간 관측을 보관한다.
원본 전체 행을 메모리에 올리지 않는다.

- 날짜·시간 범위, 숫자, 음수, NaN/무한대, 부족한 열을 검사한다. 잘못된 행은 행 번호를 포함한 오류로 알린다.
- 같은 `(행정동, 날짜, 시간)`은 첫 번째 행을 사용하고 이후 중복 행을 집계에서 제외한다.
- 코드표와 일치하는 지역이 하나도 없으면 연결 실패로 처리한다.
- 완전성의 지역 범위는 인구 파일에서 발견된 지역이다. 통째로 누락된 지역은 이 비율로 탐지하지 못한다.
- 이 폴더의 `.cache/`에 버전 4 집계를 저장한다. 파일 경로·크기·나노초 수정시각이 달라지면 다시 읽는다.
- 로딩은 `QThread`에서 실행하며, 종료 요청 시 중단 신호를 확인한 뒤 스레드를 정리한다.
- 재로딩이 실패해도 기존 분석 데이터는 유지한다.

## 검증

```bash
uv run python -m unittest discover -s tests -v
uv run app.py --check 역삼1동 --out /tmp/hotplace-charts
```
